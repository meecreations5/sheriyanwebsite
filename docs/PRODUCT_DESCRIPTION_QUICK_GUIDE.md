# SHANERYN - How to add dress details

**You do not need to fill in every field.** Only the information you enter will appear on the dress page.

1. Sign in to SHANERYN Content Studio.
2. Click **Products & Looks**, then choose your dress.
3. Open the **Descriptions** tab.
4. Add a short tagline and description if you have them.
5. Enter a price only when you want customers to see a price.
6. Click **+ Add garment** under Fabric and write the garment name and fabric. Add more garments as needed.
7. Repeat under Design Description for the outfit's design details.
8. Add any embroidery details, and optional occasion names such as Cocktail Parties.
9. Click **Save & Publish**. Click **Preview Product** to check the result on the website.

**Example**: If you enter only Fabric and Occasion description, customers see only those two headings. If the Embroidery field is empty, no Embroidery heading appears.

**Occasion filter**: The dropdown under **More Options > Catalogue Occasion Filter** is different. It decides which catalogue filter category includes the dress; it does not write the Occasion description for you.
