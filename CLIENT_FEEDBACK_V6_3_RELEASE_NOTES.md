# SHANERYN V6.3 — Client Final Content & Inner Pages

## Based on
- **Base:** Full Website V6.2. All preapproved home, collection, look details, image assets, and colour modes preserved unless listed below.

## Changes
1. **Global section labels**: raised shared eyebrow/overline labels, including **THE COLLECTION**, to a readable 15px on desktop and 12.5px on mobile.
2. **Our Story**: replaced the existing 8-section narrative with exactly two visible chapters:
   - **Founder** — the same photograph, vertical `designer` artwork, handwritten greeting, copy and signature as the homepage.
   - **Words & Impressions** — reused the existing approved testimonial teaser. No invented testimonials.
3. **Bespoke**: reuses the exact homepage Bespoke Couture *Customization* image/heading composition first; follows with three concise cards from the original Consultation page: Color Analysis, Personal Style Consultation, Occasion Styling.
4. **Past Work**: 17 supplied source photographs now appear in a responsive, aspect-ratio-preserving archival gallery with tap-to-enlarge, previous/next and Esc-to-close controls. Original faces and styling are not modified by AI. Assets optimized as WebP.
5. **Measurement guide**: the old Bespoke product-personalisation tool is preserved behind an optional, collapsed disclosure so `?look=...#measurement-studio` links from look detail continue to work. This is not an extra open editorial section.
6. **Navigation**: New Drop and Consultation links removed from the desktop/mobile/footer menus; **Styling Services** points to `bespoke.html#services`. The retired `new-drop.html` routes to Collections and `consultation.html` routes to the service cards, to avoid breaking old bookmarks. Neither is a standalone content page anymore.

## Notes
- Current enquiry controls still open the existing enquiry/contact process; no checkout or payment has been added.
- The 17 photographs were supplied as previous-work references. Publishing rights, project credits and image usage permission should be confirmed before deploying, especially for archived editorial/event imagery.
- The LinkedIn profile on the founder block remains unlinked pending the official verified URL.
- Browser layout review used inline local assets because this runtime blocks navigation to file:/// and localhost. Desktop/mobile screenshots were rendered in both colour modes where possible, and the gallery open/next/close interaction was exercised. Final deployed-device acceptance testing remains necessary.
